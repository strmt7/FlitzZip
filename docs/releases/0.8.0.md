# SuperZip 0.8.0

**Draft beta candidate.** Publication requires separate maintainer approval.
The validation-only release workflow qualifies exact ZIP/MSI artifacts before
that decision. See [beta readiness](../beta-readiness.md) for outstanding gates.

## Highlights

- Added a separate experimental Neutron star mode below efforts 1–9. It is
  GPU-only, requires a compatible AMD HIP device and the required-GPU setting,
  and selects the smallest complete candidate representation. The frontend and
  CLI use the same capability and settings rules.
- Added version-nine composition, version-ten byte-plane transforms and
  version-eleven independent entropy contexts for native blocks. The latest
  retained three-run Pythia14M study saved 1,935,715 complete modeled archive
  bytes (7.42%) against its same-setting Neutron baseline. Canterbury retained
  its preceding 1 MiB sizes. These are workload-specific results, not broad
  compression or GPU-speed superiority claims.
- Retained complete RAM-only studies over all eleven Canterbury files, all
  991 Govdocs1 thread0 files at the preceding pruning revision, and a complete
  trained model checkpoint. Records include actual HIP telemetry, zero payload
  writes, byte-exact readback and source/binary identities. Full version-eleven
  Govdocs1 coverage and controlled comparative timings remain unqualified.
- Added bounded CPU Zstandard, GPU Huffman and long-sparse native blocks while
  preserving read compatibility with older supported native versions.
- Hardened archive metadata, paths, publication, decode bounds, buffer ownership,
  packed tables and failure propagation with retained negative controls and
  direct-consumer tests. Source repairs are verified separately from historical
  public-metadata approvals and governance observations.
- Migrated to the complete pinned ROCm Core SDK 10.0.0. Release compilation
  covers six HIP targets; runtime evidence belongs to the devices exercised.
- Separated HIP kernel registration from executable startup. The exact kernel
  DLL is admitted only after trusted driver/device checks, through a versioned
  POD interface that keeps allocations and exceptions on their owning side.
  Package qualification distinguishes intact HIP binaries from missing host
  hardware; missing or modified payload DLLs remain blocking.
- Improved incremental builds, source-bound build receipts and change-aware
  verification. Crawler research tooling remains outside the shipped app.
- Separated current documentation from completed reports, retaining evidence in
  `docs/history`. Repaired all five quantitative charts to show exact observed
  ranges with visible caps; no measurements or unfavorable results were removed.
- Separated candidate validation from publication. The default manual run has
  read permission, retains checksummed artifacts and creates no release or tag.
  The explicitly enabled publisher verifies the same ZIP/MSI digests again.

## Compatibility And Limits

The runtime target remains Windows 11 x64. GPU execution requires a supported
AMD device and a compatible driver-provided HIP runtime. New version-eleven
blocks require a reader supporting that representation; this release continues
to read older supported native versions. Unsupported format methods fail
explicitly; see [the format matrix](../archive-format-support.md) and
[the native specification](../native-suzip-format.md).

Compression effort is a search budget, not a promise that every file shrinks
at every step. The retained Canterbury Neutron result is slightly smaller than
its ZIP/gzip references but larger than bzip2 and XZ. Existing numeric efforts
remain separate. An earlier reported system freeze remains unexplained; later
successful GPU tests do not establish its resolution.

The upstream NLTK advisory remains visible for development research tooling,
with its tested downstream source repair and provenance retained. The strict
hosted audit retains the acknowledged governance observations. Exact candidate
package, installer and workflow acceptance must pass before publication.
